COLBY RODRIGUEZ — INTERACTIVE PORTFOLIO

HOW TO OPEN
Open Rodriguez_website.html in a modern browser. No installation or build step is
needed. Keep the HTML, CSS, JavaScript, images, and fonts in the same folder.
If you downloaded the ZIP, extract it before opening the page.

FEATURES
- Responsive mobile navigation and active section highlighting
- Light and dark themes, saved in your browser when storage is available
- Reading progress, gentle scroll reveals, and a back-to-top button
- Clickable skill cards with accessible detail dialogs
- Copy-email button and direct email/Facebook links
- Contact form with browser validation
- Keyboard navigation and reduced-motion support

CONTACT FORM
The form opens a draft in your configured email app. Review the draft and press
Send in that app. The website does not have a mail server or backend and does
not send or store form submissions. If no email app opens, copy the displayed
email address and send your message manually. Browser clipboard restrictions
may require selecting and copying the address yourself.

EDITING
Rodriguez_website.html contains the page content.
style.css contains the layout, colors, and responsive styles.
script.js contains the interactions and skill-dialog text.
The supplied profile information, portrait, skill images, and local fonts are
retained from the original project. Update any personal details as needed.

BROWSER SUPPORT
Use a current version of Chrome, Edge, Firefox, or Safari. Core content and
direct contact links remain available with JavaScript disabled. Theme memory
and copying depend on your browser's storage and clipboard permissions.
